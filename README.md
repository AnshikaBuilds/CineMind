## ✨ What is CineMind?

**CineMind** is an AI-powered movie production platform that transforms a simple cinematic idea into a structured, production-ready **movie blueprint**.

Instead of asking one AI model to do everything, CineMind approaches filmmaking as a collaborative production pipeline.

A **Master Director Agent** coordinates specialized AI agents across storytelling, characters, storyboarding, production, marketing, music, and research — allowing each part of the filmmaking process to be handled by an agent focused on that specific creative or production responsibility.

### The result?

A single idea can evolve into:

> **Story → Characters → Storyboard → Production Plan → Music Direction → Marketing Strategy → Research → Complete Movie Blueprint**

CineMind is designed to bridge the gap between **creative imagination and structured movie development**.

---

## 🎥 Why CineMind?

Creating a movie involves far more than writing a story.

A filmmaker has to think about:

* 📖 Story and narrative structure
* 🎭 Characters and character arcs
* 🎬 Visual storytelling and shot planning
* 🎥 Production requirements
* 🎵 Music and emotional atmosphere
* 📣 Marketing and audience positioning
* 🔎 Research and contextual information

Traditionally, these responsibilities are fragmented across different tools and people.

### CineMind brings them together.

The platform turns an initial concept into a coordinated cinematic development workflow powered by multiple specialized AI agents.

# 🤖 Multi-Agent AI Architecture

CineMind uses a collection of specialized agents rather than relying on a single general-purpose generation step.

## 🎬 Master Director Agent

The orchestration layer of CineMind.

It coordinates the movie-development workflow and connects the outputs of specialized agents into a unified cinematic blueprint.

**Think of it as the AI director of the production.**

---

## 📖 Story Agent

Transforms the initial concept into the narrative foundation of the movie.

It focuses on elements such as:

* Premise
* Narrative direction
* Plot development
* Story structure
* Themes
* Conflict
* Resolution

---

## 🎭 Character Agent

Develops the people who inhabit the story.

It can generate structured character information including:

* Character identities
* Roles
* Personalities
* Motivations
* Relationships
* Character arcs

---

## 🎞️ Storyboard Agent

Converts narrative ideas into visual storytelling concepts.

It focuses on:

* Scenes
* Visual composition
* Shot concepts
* Cinematic direction
* Scene-level visual planning

This connects the **written story** to the **visual language of cinema**.

---

## 🎥 Production Agent

Moves the project from creative development toward production planning.

It considers the practical requirements of turning the cinematic concept into a production-oriented plan.

---

## 🎵 Music Agent

Designs the musical identity of the movie.

It focuses on:

* Musical atmosphere
* Emotional cues
* Tone
* Sound direction
* Music concepts for important moments

---

## 📣 Marketing Agent

Develops the audience-facing identity of the movie.

It can contribute concepts around:

* Positioning
* Audience appeal
* Promotional direction
* Marketing strategy
* Movie promotion

---

## 🔎 Research Agent

Provides research-oriented intelligence to support the movie-development process.

CineMind integrates external research capabilities into the agent pipeline so that the AI can go beyond purely generated assumptions when research is useful.

# ⚡ The CineMind Pipeline

A typical CineMind workflow looks like this:

### 01 — 💡 Start with an Idea

Provide the concept for your movie.

# 🚀 Getting Started

## Prerequisites

Make sure you have:

* **Python 3.10+**
* **Node.js 18+**
* **npm**
* A **Clerk** application
* A **Google Gemini API key**
* A **Parallel API key**

---

## 1. Clone the repository

```bash
git clone https://github.com/AnshikaBuilds/CineMind.git
cd CineMind
```

---

# 🐍 Backend Setup

Navigate into the backend:

```bash
cd backend
```

Create a virtual environment:

### Windows

```powershell
python -m venv .venv
.venv\Scripts\activate
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## 🔐 Backend Environment Variables

Create a `.env` file inside `backend/`.

```env
GEMINI_API_KEY=your_gemini_api_key
PARALLEL_API_KEY=your_parallel_api_key
CLERK_SECRET_KEY=your_clerk_secret_key
CLERK_JWT_KEY=your_clerk_jwt_key
```

> ⚠️ **Never commit your `.env` file or expose secret API keys publicly.**

---

## ▶️ Run the Backend

From the `backend` directory:

```bash
uvicorn app.main:app --reload
```

The API will run locally at:

```text
http://127.0.0.1:8000
```

---

# ⚛️ Frontend Setup

Open another terminal and navigate to:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Create:

```text
frontend/.env
```

Add:

```env
VITE_API_URL=http://127.0.0.1:8000
VITE_CLERK_PUBLISHABLE_KEY=your_clerk_publishable_key
```

Start the frontend:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

---

# 🔐 Authentication

CineMind uses **Clerk** to authenticate users and protect backend project operations.

The frontend obtains an authenticated session token and sends it to the FastAPI backend using the `Authorization` header.

```text

  ▼
Clerk Authentication
  │
  ▼
Session Token
  │
  ▼
FastAPI Authorization
  │
  ▼
```

# 🔒 Security

CineMind follows a few important security practices:

* API secrets are stored through environment variables.
* `.env` files are excluded from version control.
* Authentication is handled through Clerk.
* Backend APIs validate authenticated requests.
* Frontend environment variables use the `VITE_` prefix only for values intended for the client.
* Secret API keys remain on the backend.

# 💡 Design Philosophy

CineMind is built around one principle:

> **AI should not replace the filmmaker's imagination. It should amplify it.**

The goal isn't simply to generate more text.

The goal is to create a system where different AI capabilities work together like a creative production team — turning an idea into something structured enough to build upon.

# 🧠 What Makes CineMind Different?

### One prompt isn't enough.

A movie is a system of interconnected creative decisions.

A story affects characters.

Characters affect scenes.

Scenes affect production.

Production affects music and visual direction.

Marketing depends on the identity of the movie.

Research can influence the creative foundation.

CineMind reflects these relationships through a **multi-agent production architecture** rather than treating filmmaking as a single generation task.
